# 🛍 Final Year Project

A modern marketplace platform designed to support both **direct selling** and **bidding-based purchasing**, offering users a flexible buying and selling experience through a clean and responsive interface.

The project was built to explore scalable frontend architecture and create a production-style marketplace experience using modern web technologies.

## Live Demo

🌐 Live: https://final-year-project-rose-psi.vercel.app/

## Repository

💻 GitHub: https://github.com/a-nuj1/Final-Year-Project.git

---

## Project Overview

This platform was conceptualized as a marketplace where users could either:

- Buy products directly through standard listings
- Participate in bidding-based purchases for selected items

The frontend experience and major pages were developed to establish a scalable structure, with plans to integrate backend services for authentication, product management, bidding workflows, and seller operations.

## Installation

Clone the repository

```bash
git clone https://github.com/a-nuj1/Final-Year-Project.git
```

Go to project directory

```bash
cd Final-Year-Project
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
